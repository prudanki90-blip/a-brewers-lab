# 🔬 Predictive Molecular Recipe Engine & Kinetic Canvas

An enterprise-grade, data-driven simulation canvas for master brewers, brewing scientists, and lab engineers. This platform allows a brewer to design a beer profile, map complex multi-saccharide sugars, and model non-linear botanical extractions in software **before purchasing ingredients or starting a physical brew.**

---

## 🚀 Core Features & Scientific Engines

### 1. Relational Compound Directory (500+ Capacity)
*   **Decoupled Schema:** Ingredients are treated as chemical vectors mapping moisture metrics, sugar arrays, volatile essential oils, and variable polyphenol structures.
*   **Botanical Classifications:** Supports dense mapping for Fruits (sweet/acid metrics), Herbs (tannic structures), and Spices (essential volatile indicators).

### 2. Kinetic Extraction Physics Core
*   **Non-Linear Tannin Extraction Curve:** Tracks hydrogen bond degradation in plant cell walls. Automatically flags an **Astringency Overload Warning** when contact temperatures cross the $85^\circ\text{C}$ breakpoint or fluid pH exceeds $5.5$.
*   **Volatile Oil Preservation Index:** Simulates exponential aroma decay based on thermal thresholds. Applies an $85\%$ volatility protection shield if adjunct steps run within sub-boil whirlpool zones ($<80^\circ\text{C}$).
*   **Mass-Balance Dilution Matrix:** Automatically recalculates specific gravity conversions and liquid volume extensions when heavy adjunct fruit moisture alters the base wort.

### 3. Multi-Saccharide Sweetness Engine
*   **Carbohydrate Fractional Tracking:** Manages real-time fermentation profiles across independent carbohydrate chains (Glucose, Fructose, Sucrose, Maltose, Maltotriose, Lactose, and Dextrins).
*   **Real Extract Correction:** Evaluates accurate residual carbohydrate density using mass-balance algorithms to correct for alcohol density distortion on standard hydrometers.
